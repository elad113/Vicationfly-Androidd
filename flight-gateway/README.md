# Vicationfly Flight Gateway

Secure server-side flight-provider layer for the Android app.

Inspired by the provider/fallback architecture used by public GitHub flight projects such as `all-flights-mcp` and Duffel-based flight search services, but implemented specifically for Vicationfly.

## Providers currently wired

- **Duffel** — primary live flight-offer provider. Set `DUFFEL_ACCESS_TOKEN`.
- **Travelpayouts** — optional cached price provider. Set `TRAVELPAYOUTS_TOKEN`.

The gateway never puts provider credentials in the Android APK.

## Optional providers

The environment template reserves credentials for Skyscanner, Travelport and Sabre. Those services require legitimate partner/developer credentials and are not enabled until credentials and provider adapters are supplied.

## Run

```bash
npm install
cp .env.example .env
# add your legitimately issued provider token(s)
npm start
```

The Android app expects:

`POST /v1/flights/search`

with:

```json
{
  "origin": "TLV",
  "destination": "LHR",
  "departureDate": "2026-11-10",
  "returnDate": "2026-11-17",
  "tripType": "Round Trip",
  "adults": 1,
  "children": 0,
  "cabin": "Economy"
}
```

No fake flight offers are generated by this gateway.

**Important:** deploy this gateway on a server you control, then set the app's `FLIGHT_GATEWAY_URL` to that HTTPS endpoint. Do not commit real tokens.
